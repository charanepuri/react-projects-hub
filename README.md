## ⚡ Key Hub Features

- 🔍 **Instant Search**: Real-time filtering by project title, description, features, or tech stack tags (Keyboard shortcut: `/` to focus).
- 🏷️ **Dynamic Category Filtering**: Filter between Utilities, Data/Analytics, Lifestyle, and Reference portals with live badge count indicators.
- 📱 **Interactive Live Preview Simulator**: Preview applications right inside the hub in a responsive device switcher (Desktop, Tablet, Mobile) without leaving the page.
- 📖 **Deep-Dive Details Modal**: Comprehensive breakdown of each project’s architecture, features, and direct links to documentation/media.
- ⭐ **Local Favorites / Bookmark System**: Bookmark your favorite projects; saved persistently using browser `localStorage`.
- 🔀 **Grid & List Views**: Easily toggle between visual grid cards and compact list view.
- 📋 **One-Click Share / Copy Link**: Copy project URLs to clipboard with feedback toasts.
- 🏎️ **Ultra Fast & Lightweight**: Zero build steps required; powered by semantic HTML5, modern CSS3, Tailwind CSS CDN, and modular Vanilla JavaScript.

## 🛠️ How to Run Locally

Since this hub is built with pure web technologies, no heavy Node.js runtime or build steps are required.

### Option 1: Direct File Opening
Simply double-click `index.html` in your file explorer to open it in your favorite browser.

### Option 2: Using VS Code Live Server
1. Open the project folder in VS Code.
2. Right-click `index.html` and click **"Open with Live Server"**.

### Option 3: Python Local Server
```bash
python -m http.server 3000
# Open http://localhost:3000 in your browser
```
